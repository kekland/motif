Port of [Google's Ink Stroke Modeler](https://github.com/google/ink-stroke-modeler) to Dart.

Types are changed to be more idiomatic to Dart - e.g. usage of nullable values instead of sentinels.

The Kalman filter, predictor, tests, and `lib/stroke_modeler.dart` are ported from the C++ source using Claude Fable 5.1.
