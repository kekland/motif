# motif

An open-source vector graphics design, drawing, and animation tool.

![Screenshot](./.github/screenshot.png)

## Goals

Provide a free and open-source alternative to vector graphics design tools like Figma and Illustrator, without the predatory subscription models, paywalls, tracking, other anti-consumer practices, and useless "AI" features.

- Free and open-source on desktop (with paid mobile/tablet versions)
- Support for non-destructive procedural workflows (similar to Blender's Geometry Nodes)
- Keyframed and skeletal animation support
- Custom shaders, brushes, effects (via blueprint-based shader editor)

Future plans include:
- Multiplayer support: local (e.g. between your desktop and a tablet) and online (e.g. between multiple users) - either self-hosted, or via a provided server (with a paid subscription for the latter)
- Support for web
- Raster graphics support
- Extensions and plugin system
- MCP server and actually useful local "AI" features (e.g. for pre-filling data, tracing, etc.)
- (and potentially more stuff down the line depending on what rabbit hole i'll end up in)
